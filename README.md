This project is a Carbon Footprint Prediction System that estimates carbon emissions based on energy consumption data using machine learning techniques. It provides an interactive web interface built with Streamlit for users to input data, visualize trends, and understand environmental impact.
The system uses a trained ML model to predict emissions and displays results through charts and insights, making it useful for awareness, analysis, and decision-making.
🚀 Features
Predict carbon emissions from input data
Interactive web app using Streamlit
Data visualization (graphs & charts)
Pre-trained machine learning model (.pkl)
Uses real/semi-real dataset for analysis
🛠️ Tech Stack
Python
Streamlit
NumPy
Pandas
Matplotlib / Seaborn
Scikit-learn
📂 Project Structure

app.py                        # Main Streamlit app
requirements.txt              # Dependencies
carbon_model.pkl              # Trained ML model
energy_emissions_semireal.csv # Dataset
▶️ How to Run
Install dependencies:

pip install -r requirements.txt
Run the app: 
streamlit run app.py
